# NeuraChat Backend

Flask REST API for NeuraChat. It connects the chat interface to OpenAI and
Google AI models and stores the active chatbot configuration in Supabase.

## Features

- OpenAI and Google model support
- Runtime model selection
- Optional OpenAI web search
- Supabase-backed chatbot settings
- CORS protection for configured frontend origins

## Local setup

Create and activate a virtual environment, then install the dependencies:

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

Create a `.env` file inside the `backend` directory:

```env
OPENAI_KEY=your_openai_api_key
GOOGLE_KEY=your_google_api_key
SUPABASE_URL=your_supabase_project_url
SUPABASE_KEY=your_supabase_key
```

## Supabase schema

Run the following statement in the Supabase SQL Editor:

```sql
create table public.chatbot (
  id bigint generated by default as identity not null,
  model text null,
  full_model_name text null,
  models json null,
  name text null,
  version numeric null,
  system_prompt text null,
  constraint chatbot_pkey primary key (id)
) tablespace pg_default;
```

After creating the table, add a settings row with an `id` of `1`. The `models`
column must contain a JSON array of full model names, such as
`["openai/model-name", "google/model-name"]`.

Start the API with:

```bash
python app.py
```

The local API is available at `http://localhost:5000/api/v1`.

## Main endpoints

- `POST /chat` — send a message to the selected model
- `GET /model` — list models and return the active model
- `POST /model` — change the active model
- `GET /botname` — return the chatbot name
- `POST /botname` — change the chatbot name

If the frontend runs on a different domain, add its origin to
`ALLOWED_ORIGIN` in `app.py`.
